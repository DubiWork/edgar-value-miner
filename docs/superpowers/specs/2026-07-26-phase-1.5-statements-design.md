# Phase 1.5 — Full Financial Statements: Design Spec

**Project:** Edgar Value Miner (DubiWork/edgar-value-miner)
**Milestone:** Phase 1.5 — Full Historical Data (iCharts-style) (#6)
**Date:** 2026-07-26
**Status:** Design approved (UX + Visual); pending PM epic decomposition
**Authors:** UX researcher/designer + visual designer (via review agents), consolidated

---

## Goal

Show ALL of a company's SEC financial-report data — Income Statement, Balance Sheet, Cash Flow, every line item, all years + all quarters — visualized like Roni's iCharts / TIKR / Stockrow. The hard product constraint: **less Excely, more intuitively visual and user-friendly.** Resolve completeness-vs-restraint via progressive disclosure, visual-first defaults, and clear hierarchy.

---

## 1. Information Architecture

- New route `/company/:ticker/statements` (a research view), separate from the 5-second overview glance at `/company/:ticker`. A prominent "Explore Full Financials" CTA on the overview links to it.
- Within statements, tabs (not nested routes): **Income Statement | Balance Sheet | Cash Flow | Ratios & Margins**.
- Optional deep-link `/company/:ticker/statements/:lineItem` for shareable line-item charts.
- Header search + breadcrumbs persist across both routes.

## 2. Interaction Model (flows)

- **A — Glance→deep:** overview → "Explore Full Financials" CTA → statements page (Income tab, Annual, 10Y defaults).
- **B — Expand statement:** groups collapsed except headline group; click group header to reveal children (sparkline + value + YoY per row).
- **C — Annual⇄Quarterly:** global toggle; columns switch FY→Qn'YY; presets adjust (annual 1/3/5/10/MAX; quarterly caps 5Y default).
- **D — Range:** presets + draggable brush minimap; all grids+charts sync.
- **E — Chart a line item:** hover row → chart icon → slide-over panel (desktop) / bottom-sheet (mobile) with full series, CAGR/high/low, up-to-3 comparison overlays, accessible data table.

## 3. Progressive Disclosure (4 levels)

1. **Glance (overview):** 7 metric cards + 3 charts + valuation. Zero line items, zero tables.
2. **Statement grid default:** only headline groups expanded (~4-10 rows), each with inline sparkline + latest value + YoY. Collapsed groups show only their subtotal row.
3. **Full group expansion:** reveals child line items with full period columns.
4. **Line-item chart drill-down:** full time series, comparison, inflection annotation.

Never shows all 35+ line items × 40+ periods unless explicitly requested.

## 4. The Humanized Statement Grid

- Collapsible groups with **colored left-border accents** (differentiation anchor): green=revenue/assets, red=expenses/liabilities, indigo=equity/cash.
- Bold, visually-distinct subtotal rows (only rows visible when group collapsed).
- **Inline sparkline (~60px, raw SVG)** on every row — trend at a glance.
- Color-coded values (negative = danger) + **YoY badge (chip WITH ↑/↓ arrow — never color-alone)**.
- Sticky top period header + sticky left label column. Subtle zebra (no heavy borders). 16px gaps between groups.
- **Most-recent period on the LEFT** (TIKR/Stockrow convention).
- `font-variant-numeric: tabular-nums` on all values (column alignment — the anti-Excel detail).
- Number format toggle: Abbreviated ($394B) default / Raw (for copy-paste).
- Default expanded/collapsed state defined per statement (headline groups open).

## 5. Control Bar (sticky, global)

`[Annual|Quarterly]` segmented toggle + `[1Y 3Y 5Y 10Y MAX]` pill presets + 200×24px draggable **brush minimap** (Revenue area chart) + `[$Abbreviated|Raw]` toggle. Global (all views sync), URL-synced (`?range=5Y&granularity=quarterly`), persisted to localStorage per-company. Default: Annual + 10Y (or MAX).

## 6. Chart Drill-Down

Desktop slide-over (440px, backdrop blur) / mobile bottom-sheet (72vh, drag handle). Stats block (latest, CAGR, high/low) + full chart + comparison overlays (colorblind-safe: blue+orange first, + line-style variation) + accessible data table.

## 7. Visual System ("Precision Ledger")

Surgical extension of the existing token system (light/dark, `useChartTheme()`). NEW tokens (exact light+dark values + verified WCAG AA in the visual spec source): `--color-group-{revenue,expense,equity}` (+border/+fill), `--color-subtotal-*`, `--color-row-zebra`, `--color-sparkline-*`, `--color-yoy-*`, `--color-data-gap-*`, `--period-pill-active-*`, sticky-header surfaces. No pure black; 4-level dark elevation. No glassmorphism (stays opaque, consistent with existing cards).

## 8. Sparklines

**Raw SVG, ~40 lines**, reads `useChartTheme()`. NOT a new library (@nivo would add ~45KB for a 60px cell; Recharts LineChart overhead too heavy at 30-50 sparklines/page). Monotone area, 1.5px stroke, gradient fill, trend-colored (start vs end).

## 9. Mobile

Grid → latest-2-periods + sparkline + YoY; control bar wraps 2 rows (minimap on row 2, h-scroll); chart = full-screen bottom sheet; 44px touch targets; period pills grow to 36px.

## 10. Accessibility (WCAG 2.1 AA)

`role="grid"` + aria row/col indices; group headers `aria-expanded`; sparklines `aria-hidden` (values in cells); drill panel `role="dialog"` + focus trap + focus return; keyboard nav (Enter/Space expand, arrows move, Esc close); YoY arrows + signs (not color-alone); `prefers-reduced-motion` disables transitions; every new text/bg pair verified AA.

## 11. Data Gaps

Em-dash `—` + subtle `--color-data-gap-bg` tint + `aria-label="Data not available"` + `title`; omit from sparkline; consistent across all 4 tabs; transition-period columns footnoted.
